Resuelve el siguiente problema en Scala version 2.13, usando ESTRICTAMENTE el paradigma funcional.

Problema: Word Frequency
﻿Escribe una funcion en Scala que, dada una lista de palabras (strings), retorne
un diccionario/mapa que asocie cada palabra unica con el numero de veces que aparece.

Requisitos:
- El nombre de la funcion debe ser exactamente: wordFrequency
- Si la lista de entrada esta vacia, retorna una estructura vacia.
- No uses librerias externas, solo las de la biblioteca estandar del lenguaje.

Ejemplo de entrada:  ["the", "fox", "the"]
Ejemplo de salida:   {"the": 2, "fox": 1}

Incluye al final del archivo 3 casos de prueba simples usando assert o el mecanismo
estandar del lenguaje para validar tu implementacion.


=== REQUISITOS ADICIONALES ===

1. LENGUAJE Y VERSION: Usa EXCLUSIVAMENTE Scala 2.13. Usa las caracteristicas nuevas de 2.13 cuando esten disponibles.

2. PARADIGMA FUNCIONAL: Usa val, colecciones inmutables, map(),filter(),foldLeft(),flatMap(). Usa @tailrec. Evita var y mutable.*.

3. NOMBRE DE FUNCION: Exactamente "wordFrequency".

4. BIBLIOTECA ESTANDAR UNICAMENTE: No uses librerias de terceros.

5. TESTS: Incluye al final 3 casos de prueba usando el mecanismo estandar de Scala.
