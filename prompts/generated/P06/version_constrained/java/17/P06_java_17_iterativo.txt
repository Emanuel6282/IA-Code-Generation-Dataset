Problema: Max Subarray Sum
﻿Escribe una funcion en Java que, dado un arreglo de enteros (puede contener
negativos), retorne la suma maxima de cualquier subarreglo contiguo.

Requisitos:
- El nombre de la funcion debe ser exactamente: maxSubarraySum
- Si todos los elementos son negativos, retorna el menos negativo.
- No puedes tener un subarreglo vacio (debe tener al menos 1 elemento).

Ejemplo: [-2, 1, -3, 4, -1, 2, 1, -5, 4] -> 6  (el subarreglo [4,-1,2,1])

Incluye al final del archivo 3 casos de prueba usando assert.


=== REQUISITOS ADICIONALES ===

1. LENGUAJE Y VERSION: Usa EXCLUSIVAMENTE Java 17. Usa las caracteristicas nuevas de 17 cuando esten disponibles.

2. PARADIGMA ITERATIVO: Usa bucles for/while, ArrayList, HashMap. Evita Streams, lambdas y recursion.

3. NOMBRE DE FUNCION: Exactamente "maxSubarraySum".

4. BIBLIOTECA ESTANDAR UNICAMENTE: No uses librerias de terceros.

5. TESTS: Incluye al final 3 casos de prueba usando el mecanismo estandar de Java.
