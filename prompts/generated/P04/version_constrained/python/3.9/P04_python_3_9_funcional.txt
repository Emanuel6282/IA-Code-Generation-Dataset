Problema: Balanced Parentheses
﻿Escribe una funcion en Python que, dada una cadena que contiene solo los caracteres
"(", ")", "[", "]", "{", "}", retorne verdadero si todos los parentesis/corchetes estan
correctamente balanceados y cerrados en orden. Retorna falso en caso contrario.

Requisitos:
- El nombre de la funcion debe ser exactamente: is_balanced
- Una cadena vacia es considerada balanceada.

Ejemplos: "()" -> true | "([)]" -> false | "{[]}" -> true

Incluye al final del archivo 3 casos de prueba usando assert.


=== REQUISITOS ADICIONALES ===

1. LENGUAJE Y VERSION: Usa EXCLUSIVAMENTE Python 3.9. Usa las caracteristicas nuevas de 3.9 cuando esten disponibles.

2. PARADIGMA FUNCIONAL: Usa inmutabilidad. Emplea map(),filter(),functools.reduce(). Evita for/while con estado mutable.

3. NOMBRE DE FUNCION: Exactamente "is_balanced".

4. BIBLIOTECA ESTANDAR UNICAMENTE: No uses librerias de terceros.

5. TESTS: Incluye al final 3 casos de prueba usando el mecanismo estandar de Python.
